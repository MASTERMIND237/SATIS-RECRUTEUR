1. PRÉSENTATION DU PROJET
1.1 Contexte
"Satis-Tuteur" est une application de recrutement créée par Essongue Marcien. L'objectif est d'évaluer la façon de penser business et communication des candidats via des questions ouvertes, dans une expérience immersive et fluide.
Enjeux stratégiques :
Créer une expérience mémorable qui reflète la culture de "Satis-Tuteur".
Plonger le candidat dans le contexte de l'entreprise avant qu'il ne réponde.
Recueillir des réponses spontanées et authentiques (effet "question qui apparaît et disparaît").
Renforcer la marque employeur via une interface épurée et un parcours guidé.
Domaine : Recrutement / Évaluation comportementale
1.2 Objectifs
Objectif principal :Fournir un outil permettant à un candidat de :
Être mis en contexte (2 écrans introductifs).
Répondre à une série de questions ouvertes en mode "in-and-out".
Recevoir un message de remerciement personnalisé.
Envoyer automatiquement ses réponses par email au recruteur via Formspree.
Objectifs secondaires :
Créer une expérience utilisateur fluide (in-and-out) qui met à l'aise le candidat.
Renforcer l'identité de marque "Satis-Tuteur" tout au long du parcours.
Permettre une modification facile des questions et des textes introductifs.
Assurer une sécurité maximale sans exposer de clés API ou d'identifiants.
Indicateurs de succès :
Taux de complétion > 90%.
Temps de passation moyen < 10 minutes.
Qualité des réponses (évaluée manuellement).
Taux de délivrabilité des emails > 99%.
1.3 Description de l'existant
Environnement actuel :
Aucun outil dédié n'existe aujourd'hui.
Les évaluations se font via des entretiens oraux ou des questionnaires Google Forms standard.
Aucune expérience "in-and-out" ni mise en contexte immersive.
Environnement cible :
Plateforme : Navigateur web moderne (Chrome, Firefox, Safari, Edge).
Hébergement : Static hosting (Netlify, Vercel, GitHub Pages, ou Cloudflare Pages).
Stockage : Aucune base de données. Les réponses sont envoyées par email uniquement.
Envoi d'emails : Formspree (service de formulaire sécurisé sans backend).
1.4 Critères d'acceptabilité du produit
Procédure de validation :
Le recruteur ouvre l'application.
Il simule une session candidat (parcours complet).
Il vérifie que l'email reçu contient toutes les réponses dans l'ordre.
Il vérifie que les animations in-and-out sont fluides.
Il vérifie que les données sont bien formatées dans l'email.
Critères d'acceptation :
✅ L'application s'ouvre en < 2 secondes.
✅ Les 2 écrans introductifs s'affichent en in-and-out.
✅ Chaque question apparaît avec animation (fade-in) et disparaît (fade-out).
✅ Les réponses sont envoyées par email en < 5 secondes après soumission finale.
✅ Le message de remerciement affiche le nom du candidat et un emoji.
✅ L'interface est responsive (mobile-first).
✅ La marque "Satis-Tuteur" est visible sur tous les écrans.
✅ Aucune clé API ou identifiant n'est exposé dans le code frontend.
✅ Les données sont envoyées via HTTPS vers Formspree.

Annexe B : Intégration avec Formspree
Configuration :
Créez un compte sur Formspree
Créez un nouveau formulaire et récupérez l'ID (ex: xeqazvdl)
Ajoutez l'ID dans le fichier de configuration
Envoi des données (JavaScript) :
// Envoi vers Formspree
async function sendToFormspree(data) {
    const formspreeId = config.formspreeId;
    const response = await fetch(`https://formspree.io/f/${formspreeId}`, {
        method: 'POST',
        headers: {
            'Content-Type': 'application/json',
            'Accept': 'application/json'
        },
        body: JSON.stringify(data)
    });
    
    if (!response.ok) {
        throw new Error('Erreur lors de l\'envoi');
    }
    return response.json();
}
// Utilisation
const data = {
    name: candidateName,
    email: candidateEmail,
    answers: JSON.stringify(answers), // Les réponses formatées
    // Formspree envoie tout à l'email configuré
};
await sendToFormspree(data);
